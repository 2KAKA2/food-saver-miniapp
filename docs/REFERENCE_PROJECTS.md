## EverShelf

- 仓库：<https://github.com/dadaloop82/EverShelf>
- 评估版本：`661430cca9a7328a6dd225c72680960678885b0a`（2026-08-10）
- 许可证：MIT

EverShelf 是一个自托管的家庭库存与菜谱 PWA，覆盖批次、保质期、开封状态、条形码、购物清单、AI 菜谱和离线能力。它适合用来校验产品功能是否贴近日常家庭场景。

本项目当前吸收的产品思路：

- 本地后端断连时展示上一次库存快照，并清楚提示数据时间。
- 所有离线数据按家庭空间隔离，退出登录后清除。
- 优先保证触控操作清晰，并保留首页快速录入和快速生成菜谱入口。
- AI 不可用时明确显示降级来源，不假装是真实模型结果。

没有直接复制 EverShelf 源代码。以下能力暂不采用：

- 不采用 PHP 单体后端；继续使用现有 FastAPI、SQLAlchemy、Vue3 和 uni-app 分层结构。
- 不实现离线写入队列；家庭多人共享时，离线写入容易产生数量冲突，首版仅提供只读快照。
- 条形码、开封后保质期、购物清单和收藏属于后续增强，不进入当前上线关键路径。
- 不采用单一可选 API Token 作为用户身份；继续使用微信登录、服务端会话和家庭成员权限模型。
