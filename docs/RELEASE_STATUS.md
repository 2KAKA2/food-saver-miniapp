# 发布状态与验证证据

更新日期：2026-08-17

## 已验证

- 微信登录采用小程序 code 到服务端 `code2session`，客户端不接触 AppSecret。
- 服务端会话仅保存令牌哈希，业务接口按登录用户和家庭成员关系鉴权。
- 多家庭创建、邀请、加入、切换、移除成员、退出和所有者权限已经具备测试覆盖。
- 库存、菜谱和消耗记录按家庭隔离；跨家庭访问测试返回拒绝。
- 菜谱制作采用数据库事务和幂等键，重复请求不会重复扣减库存。
- 图片上传限制为 5 MB，仅接受 JPG、PNG、WebP，并校验内容签名与声明格式一致。
- 登录不读取微信昵称或头像；用户可自行设置家庭显示昵称。
- 用户协议、隐私政策、退出登录和账号注销入口均已提供。
- 生产配置会拒绝 SQLite、缺少微信/AI/Redis 配置、开发登录和演示数据。
- 数据库与 Redis 就绪检查、请求编号、脱敏访问日志和异常日志已实现。
- MySQL 备份生成 SHA-256 校验文件；恢复操作要求明确确认并自动创建恢复前备份。

## 手机端端到端验收

在 390 × 844 手机视口、本地开发登录、关闭真实 AI Key 的条件下完成：

1. 登录并进入空库存首页。
2. 首页显示三步首次使用引导，无横向溢出。
3. 通过快捷项录入 2 个西红柿。
4. AI 菜谱页读取到该库存并生成降级菜谱。
5. 确认制作并消耗 1 个西红柿。
6. 返回后库存显示为 1 个。
7. 菜谱历史显示对应菜谱状态为“已制作”。
