# 发布状态与验证证据

更新日期：2026-08-17

## 已验证

- 微信登录采用小程序 code 到服务端 `code2session`，客户端不接触 AppSecret。
- 服务端会话仅保存令牌哈希，业务接口按登录用户和家庭成员关系鉴权。
- 多家庭创建、邀请、加入、切换、移除成员、退出和所有者权限已经具备测试覆盖。
- 小程序可修改家庭名称、撤销邀请码、转让家庭所有者和退出家庭；家庭页手机布局无横向溢出。
- 库存、菜谱和消耗记录按家庭隔离；跨家庭访问测试返回拒绝。
- 菜谱制作采用数据库事务和幂等键，重复请求不会重复扣减库存。
- AI 返回内容按不可信输入处理：限制条目数量和字段长度，并用真实库存覆盖模型提供的名称、单位和可用量；模型不能伪造库存或超量消耗。
- 图片识别结果逐项校验，非法数量和格式会被丢弃，最多返回 20 项且仍须用户确认后才会入库。
- 图片上传限制为 5 MB，仅接受 JPG、PNG、WebP，并校验内容签名与声明格式一致。
- 登录不读取微信昵称或头像；用户可自行设置家庭显示昵称。
- 登录时服务端校验并保存用户同意的协议版本和时间；协议更新后，旧版本会话自动失效并要求重新阅读和登录。
- 首发版本显式关闭 DCloud `uniStatistics`，不向第三方统计服务上报页面访问和活跃数据。
- 用户协议、隐私政策、退出登录和账号注销入口均已提供。
- 隐私政策的运营主体、协议日期和 AI 服务方由正式构建配置注入；占位值会被发布体检阻止。
- 已生成原创 1254 × 1254 PNG 小程序头像，核心图形位于安全区且不含文字、商标或水印。
- 原生底部导航已为五个页面配置 81 × 81 PNG 图标，并提供灰色默认态和绿色选中态。
- 生产配置会拒绝 SQLite、缺少微信配置、开发登录和演示数据；AI/Redis 可通过开关按部署规模设为强制依赖。
- 生产环境不公开 Swagger、ReDoc 和 OpenAPI 文档；微信正式构建开启服务器域名校验。
- 数据库与可选 Redis 就绪检查、请求编号、脱敏访问日志和异常日志已实现。
- MySQL 备份生成 SHA-256 校验文件并默认轮转 30 天；恢复操作要求明确确认并自动创建恢复前备份；容器日志限制为 5 × 10 MB。
